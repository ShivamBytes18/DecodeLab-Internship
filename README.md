## 📁 Project Structure

```
portfolio/
├── index.html      # Main HTML markup & page structure
├── styles.css      # All styling, design tokens & responsive layout
└── script.js       # Interactivity — nav, scroll animations, form
```

---

## ✨ Features

- **Responsive Design** — Mobile-first layout, works across all screen sizes
- **Smooth Scroll Animations** — IntersectionObserver-based reveal on scroll
- **Animated Hero Avatar** — CSS morphing blob with floating chips
- **Mobile Navigation** — Hamburger menu with keyboard & outside-click dismissal
- **Active Nav Highlighting** — Highlights the current section in the navbar as you scroll
- **Project & Skills Sections** — Hover interactions on cards and skill tags
- **Contact Form** — Client-side validation with a simulated submission state
- **Accessible** — Skip link, ARIA labels, keyboard navigable throughout
- **Reduced Motion Support** — Respects `prefers-reduced-motion` media query

## 🚀 Getting Started

No installation or build step needed.

### Run Locally

```bash
# Clone the repository
git clone https://github.com/ShivamBytes18/portfolio.git

# Navigate into the folder
cd portfolio

# Open in browser
open index.html
# or just double-click index.html
```

### Deploy to GitHub Pages

1. Push the repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)` folder
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## 🎨 Design Tokens

All colours and spacing live in CSS custom properties at the top of `styles.css`, making it easy to re-theme:

```css
:root {
  --mocha:      #A5856E;   /* Primary accent    */
  --blue:       #A0D4E0;   /* Secondary accent  */
  --grey:       #F2F0EA;   /* Page background   */
  --ink:        #1e1b18;   /* Body text         */
}
```
